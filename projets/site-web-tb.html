Prototype de site web pour une télévision locale

Ce projet présente un prototype de site web développé pour une télévision locale.

L’objectif était d’explorer une refonte moderne du site existant, avec une interface orientée contenus, vidéo et diffusion en direct.

Le prototype comprend une partie publique ainsi qu’un espace d’administration permettant de gérer les émissions, les contenus promotionnels et certains éléments visuels comme les slides.

Technologies utilisées

Frontend
HTML CSS JavaScript
Backend
Python Flask Jinja2
Intégration
YouTube Google Maps

Fonctionnalités clés

Gestion du contenu

Création et modification des émissions, contenus promotionnels, slides et autres éléments via une interface d’administration.

Diffusion vidéo

Intégration du direct de la chaîne et de contenus YouTube.

Intégrations externes

Utilisation de services externes comme YouTube et Google Maps pour enrichir l’expérience utilisateur.

Interface responsive

Navigation adaptée aux ordinateurs, tablettes et smartphones.

Approche de développement

Ce projet a été développé avec l’aide d’outils d’intelligence artificielle utilisés comme assistance au développement. Le concept, les choix techniques, les tests et les ajustements ont toutefois été réalisés par mes soins tout au long du projet.
