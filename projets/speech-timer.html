Outil web de suivi du temps de parole en direct

Speech Timer est une application web interactive conçue pour suivre en temps réel le temps de parole de plusieurs intervenants lors d'un débat ou d’une réunion.

Le projet a été pensé pour une utilisation lors d'enregistrements d'émissions, avec une interface rapide à utiliser sous pression et des interactions simples via clic ou raccourcis clavier.

L’application permet de chronométrer plusieurs participants, mettre une session en pause, ajuster manuellement les temps et visualiser rapidement les écarts grâce à des alertes visuelles.

Technologies utilisées

Frontend
HTML CSS JavaScript

Fonctionnalités clés

Chronométrage temps réel

Suivi simultané du temps de parole de plusieurs intervenants avec affichage clair et lisible.

Raccourcis clavier

Contrôle rapide sans navigation souris pour une utilisation fluide en situation de stress.

Ajustements manuels

Possibilité de corriger les temps en cas d’erreur ou de pause imprévue.

Alertes visuelles

Signalisation immédiate des écarts de temps de parole.

Interface personnalisable

Configuration de nombre d'intervenants, des noms et des seuils d'alerte.

Réorganisation libre

Déplacement dynamique des cartes selon les besoins.

Interface responsive

Utilisation adaptée sur ordinateur, tablette et mobile.

Connexion sécurisée

Gestion sécurisée des connexions utilisateurs.
