Habillage web pour l’émission météo

Ce projet est utilisé pour la production de l’émission météo de TeleBielingue. Les cartes météo sont affichées via CasparCG, puis enregistrées pour être intégrées ensuite au montage de l’émission.

Les pages météo sont réalisées en HTML, CSS et JavaScript, puis servies depuis un serveur web interne. Le système génère automatiquement les différentes cartes nécessaires : prévisions du matin, prévisions de l’après-midi, températures et prévisions sur quatre jours.

Les données météo proviennent d’un fichier XML reçu quotidiennement. Un script JavaScript lit ce fichier et remplit automatiquement les différentes cartes, ce qui permet de produire rapidement l’émission sans intervention manuelle.

Fonctionnalités clés

Import automatique des données météo

Lecture quotidienne du fichier XML pour alimenter automatiquement les contenus météo.

Génération des cartes météo

Prévisions du matin, de l’après-midi, températures et prévisions des quatre prochains jours, avec positionnement précis des éléments graphiques.

Affichage via CasparCG

Pages web conçues pour être affichées dans CasparCG lors de l’enregistrement de l’émission.

Utilisation en production réelle

Outil utilisé quotidiennement pour la production de l’émission météo de TeleBielingue, avec une structure facilement adaptable selon les besoins.

Approche de développement

Ce projet a été développé avec l’aide d’outils d’intelligence artificielle utilisés comme assistance au développement. Le concept, les choix techniques, les tests et les ajustements ont toutefois été réalisés par mes soins tout au long du projet.
