Habillage web pour l’émission météo

Ce projet a été développé dans le contexte de la production de l’émission météo de TeleBielingue, avec pour objectif de créer les différentes pages météo utilisées à l’antenne via le programme graphique CasparCG.

Les pages sont servies depuis un serveur web interne, puis affichées dans CasparCG pour l'enregistrement de l'émission. Le système permet de générer plusieurs slides météo : prévisions du matin, prévisions de l’après-midi, températures et prévisions sur quatre jours.

Les données météo sont fournies sous forme de fichiers XML. Le programme lit ces données et affiche automatiquement les éléments correspondants sur les différentes pages.
