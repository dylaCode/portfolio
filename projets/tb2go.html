TB2Go

TB2Go est une application web développée pour centraliser et simplifier la gestion du matériel technique au sein d’une télévision locale.

Le projet est né d’un besoin concret : améliorer la réservation, le suivi et la maintenance des équipements utilisés quotidiennement par les équipes de production.

L’application permet de gérer les réservations de matériel, les utilisateurs, les catégories d’équipement, l’historique des emprunts ainsi que le suivi des incidents techniques.

Technologies utilisées

  • Frontend : HTML, CSS, JavaScript, Bootstrap
  • Backend : Python / Flask
  • Templates : Jinja2
  • Base de données : SQLite
  • Versioning : Git / GitHub
  • Déploiement : PythonAnywhere

Fonctionnalités clés

  • Gestion des utilisateurs avec rôles et permissions
  • Système de réservation de matériel avec calendrier intégré
  • Historique complet des emprunts et retours
  • Suivi et documentation des incidents techniques
  • Gestion centralisée des équipements et catégories
  • Interface responsive adaptée desktop, tablette et mobile
  • Gestion sécurisée des connexions utilisateurs

Approche de développement

Ce projet a été développé avec une assistance d’outils d’intelligence artificielle, utilisés comme support au développement et au prototypage rapide. J’ai défini les besoins, orienté les choix fonctionnels, testé les fonctionnalités et piloté les évolutions du projet.
