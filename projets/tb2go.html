Gestion et réservation de matériel

TB2Go est une application web développée pour centraliser et simplifier la gestion du matériel technique au sein d’une télévision locale.

Le projet est né d’un besoin concret : améliorer la réservation, le suivi et la maintenance des équipements utilisés quotidiennement par les équipes de production.

L’application permet de gérer les réservations de matériel, les utilisateurs, les catégories d’équipement, l’historique des emprunts et le signalement des incidents techniques.

Technologies utilisées

Frontend
HTML CSS JavaScript Bootstrap
Backend
Python Flask Jinja2
Base de données
SQLite

Fonctionnalités clés

Gestion des utilisateurs

Création de comptes avec rôles et permissions pour contrôler l’accès aux différentes fonctionnalités.

Réservation de matériel

Gestion des disponibilités et des emprunts de matériel via un calendrier intégré.

Suivi du matériel

Fiches détaillées avec catégories, images, informations techniques et historique des emprunts.

Incidents techniques

Signalement, documentation et suivi des incidents techniques pour faciliter leur résolution.

Notifications automatiques

Envoi d’emails automatiques pour certaines actions et mises à jour importantes.

Interface responsive

Utilisation adaptée sur ordinateur, tablette et smartphones.

Approche de développement

Ce projet a été développé avec l’aide d’outils d’intelligence artificielle utilisés comme assistance au développement. Le concept, les choix techniques, les tests et les ajustements ont toutefois été réalisés par mes soins tout au long du projet.
